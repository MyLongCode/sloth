Написал программу для автоматизации проверок заданий преподавателям на платформе "Алгоритмика"

Как сделать так, чтобы заработало?
1. Установить Python (если его нету)
2. Скачать файл
3. Написать в терминал `pip install requests`
4. Авторизироваться на платформе
5. F12 -> Network
6. Просмотреть любой запрос
7. Скопировать оттуда Coockie
8. Создать файл coockies.txt и вставить туда куки
9. Запустить программу и нажать кнопку "RUN ALL"
10. Убрать галочку с "Dry Run" и нажать кнопку "RUN Step 4 POST"
